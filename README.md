# Протокол: Двойник

Конкурсный прототип 2D-игры, которая собирает поведенческие данные игрока и создаёт персонального финального противника.

В игру встроена временная нейросеть PyTorch `10 состояний × 25 признаков → GRU(64, 2 слоя) → 32 → 10 действий` с 44 892 обучаемыми параметрами. Сначала она обучается на прошлых сессиях, затем дообучается под текущего игрока и управляет прогнозами финального двойника. RTX-видеокарта используется автоматически.

## Быстрый запуск на Windows

Установите 64-битный Python 3.10 или 3.11 (также поддерживаются 3.12 и 3.13), а затем дважды щёлкните `start_game.bat`. При первом запуске скрипт автоматически выберет поддерживаемую версию Python, создаст локальное окружение и установит только Pygame. Этого достаточно, чтобы играть и собирать датасет: при отсутствии PyTorch игра использует резервную MLP.

Python 3.14 пока не подходит для запуска: у закреплённой версии Pygame нет готового Windows-пакета для этой версии. Если папка `.venv` уже была создана через Python 3.14, удалите только `.venv` и снова запустите `start_game.bat` после установки Python 3.10 или 3.11.

Для обучения полной GRU на своём компьютере один раз запустите `install_ai.bat`. Он отдельно установит NumPy и PyTorch с CUDA 13.0. Участникам, которые только проходят игру и возвращают папку `data`, этот большой пакет не нужен.

Ручной запуск:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-player.txt
.\.venv\Scripts\python.exe run_game.py
```

Полная установка ИИ из терминала:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Переобучить модели на уже сохранённых прохождениях без запуска игры:

```powershell
.\.venv\Scripts\python.exe train_ai.py
```

## Управление

- `WASD` — движение;
- левая кнопка мыши — дальняя атака;
- правая кнопка мыши — ближняя атака;
- `Space` — рывок;
- `Shift` — блок;
- `Q` — лечение;
- `1–3` — выбранные способности;
- `F` — ложная атака для обмана поведенческого профиля;
- `Esc` — возврат в меню.

В главном меню:

- `1` или `Enter` — начать игру;
- `2` или `E` — открыть редактор арен;
- `3` — открыть обучение механикам и практическую арену;
- `↑` и `↓` или мышь — выбрать кнопку.
- `F9` — включить или выключить сокращённый конкурсный демо-режим.

## Игровая последовательность

1. Игрок выбирает или создаёт именной профиль, затем выбирает оружие и три способности из семи. Данные разных людей сохраняются раздельно, а двойник получает тот же набор способностей.
2. Три тренировочные арены по 35 секунд запускают новые волны и собирают данные с частотой 5 записей в секунду. Задания арен: удержание зоны, сбор энергетических ядер и защита системного ядра. Дополнительные калибровочные испытания просят применить редкие действия: блок, рывок, идеальное уклонение и лечение. После окончания таймера новые волны не появляются: нужно выполнить задание и уничтожить оставшихся противников.
3. Между аренами игрок выбирает постоянные улучшения здоровья, энергии, скорости, урона, восстановления атак или лечения.
4. Игра делит записи по игрокам на обучение/проверку/тест: сессии одного человека не могут оказаться в разных частях выборки. Затем формируются окна из 10 состояний, а редкие действия балансируются взвешенной выборкой.
5. Общая GRU предварительно обучается на других игроках, а её копия дообучается на сессиях текущего человека. После этого запускается короткий безопасный этап offline RL с реальной наградой за нанесённый и полученный урон, блоки, уклонения, лечение, убийства и выполнение задания. Обновление принимается только при сохранении контрольной точности.
6. Двойник прогнозирует действия через общий интерфейс `predict()` и показывает уверенность прогноза.
7. Финальный бой состоит из фаз копирования, предсказания и искажения.
8. Пока модель обучается в отдельном потоке, интерфейс и анимированный фон продолжают работать. Экран профиля показывает качество датасета, предупреждения о недостающих действиях, тестовую точность, macro-F1 и интерактивную матрицу ошибок. Нажатие на красную ячейку открывает соответствующий момент повтора, а клавиша `A` — графики loss/accuracy/F1, историю сессий и сравнение общей и персональной модели.

## Оружие

- импульсный автомат — универсальная стрельба;
- энергетический дробовик — пять зарядов с разбросом;
- рельсовая винтовка — редкие мощные выстрелы;
- парные клинки — усиленный и ускоренный ближний бой.

На аренах находятся разрушаемые энергетические контейнеры. Они блокируют движение и линию огня, получают урон от снарядов и ближних атак.

## Противники

- штурмовик быстро сокращает дистанцию и атакует сериями;
- снайпер долго прицеливается и наносит большой урон;
- щитовик блокирует большую часть урона спереди;
- телепортер периодически меняет позицию;
- инженер устанавливает турели и ловушки;
- копировщик временно блокирует способности игрока;
- цифровой двойник проходит три фазы и применяет выбранные игроком способности.

## Способности

Доступны ловушка, энергетическая волна, отражение снарядов, телепортация, временный щит, ложный клон и замедление. Перед сессией нужно выбрать три.

Рывок непосредственно перед попаданием считается идеальным уклонением: время замедляется, а часть энергии восстанавливается.

Противники заранее обозначают ближние и дальние атаки. Быстрые последовательности боевых действий образуют комбинации и возвращают часть энергии:

- выстрел → рывок → ближний удар;
- блок → рывок → выстрел;
- ближний удар → рывок → выстрел;
- выстрел → блок → ближний удар.

CSV и метаданные сохраняются в папке `data/`. Каждая строка содержит `player_id`, состояние, действие, время арены, награду и измеренные исходы действия: урон, успешный блок, идеальное уклонение, эффективное лечение, убийство и прогресс задания. Старые файлы читаются без преобразования и получают отдельные анонимные идентификаторы. Все признаки нормализованы в диапазон `[-1, 1]`. Модели и воспроизводимый список train/validation/test-игроков сохраняются в `models/`:

- `general_gru.pt` — общая предварительно обученная модель;
- `personal_gru.pt` — персональная модель после supervised- и offline-RL-этапов;
- `session_split.json` — разделение без утечки соседних кадров;
- `ai_metrics.json` — точность, macro-F1, матрица ошибок и данные RL.
- `metrics_history.json` — история качества общей и персональной модели по сессиям.

Реестр именных профилей хранится в `data/players.json`, а подробные повторы для интерактивного разбора ошибок — в `data/replay_<id>.json`. Экран контроля качества показывает покрытие десяти классов, объём выборки, долю настоящих наград и предупреждает, какие действия нужно выполнить чаще.

При загрузке старых записей поле `last_action` автоматически сдвигается на предыдущий момент, чтобы правильный ответ не попадал во вход модели. В новых записях атаки, рывки и лечение сохраняются сразу в момент события, поэтому редкие действия больше не теряются между обычными замерами раз в 0,2 секунды.

## Дополнительные режимы

- **Повтор:** траектория игрока и ключевые события каждой арены.
- **Призрак:** прошлая сессия полупрозрачно воспроизводится во время новой калибровки.
- **Редактор:** стены, аптечки, точка игрока, цель, разрушаемые контейнеры и любые типы противников. `R` поворачивает стену, `C` меняет её длину, `M` переключает размещение/перемещение/удаление, `G` выбирает режим «Уничтожение», «Выживание» или «Удержание точки», `6` выбирает контейнер, `S` сохраняет арену, `T` запускает проверку.
- **Интерактивное обучение:** шесть практических этапов для движения, стрельбы, ближней атаки, блока, рывка и способности.
- **Конкурсный режим:** `F9` сокращает калибровку до 14 секунд на арену и ускоряет обучение сети.
- **Лаборатория:** сравнение распределений действий и тепловых карт сохранённых сессий.
- **Турнир:** два последних цифровых профиля автоматически сражаются друг с другом. Если данных недостаточно, используются демонстрационные стили.

## Структура

```text
digital_twin_game/
├── actions.py          # 10 классов действий
├── analysis.py         # комбинации и тепловая карта
├── abilities.py        # семь выбираемых способностей
├── arena.py            # арены, препятствия и аптечки
├── background.py       # анимированные созвездия фоновых экранов
├── behavior.py         # прозрачная поведенческая статистика
├── calibration.py      # испытания для сбора редких действий
├── config.py           # настройки игры
├── data.py             # сбор и сохранение обучающих примеров
├── data_quality.py     # аудит датасета и предупреждения
├── editor.py           # редактор пользовательских арен
├── entities.py         # игрок, враги, снаряды
├── features.py         # построение 25 признаков
├── fx.py               # частицы, числа урона, звук и тряска
├── game.py             # основной цикл и экраны
├── lab.py              # загрузка и сравнение сессий
├── model_interface.py  # общий контракт моделей прогнозирования
├── neural_model.py     # резервная MLP без внешних зависимостей
├── players.py          # именные профили и разделение игроков
├── sequence_data.py    # окна из 10 состояний и разделение по игрокам
├── torch_model.py      # GRU, балансировка, метрики, персонализация и offline RL
├── objectives.py       # задания тренировочных арен
├── replay.py           # запись, повтор и призрак
├── tournament.py       # автоматические бои профилей
├── upgrades.py         # постоянные улучшения между аренами
├── weapons.py          # четыре вида оружия и их характеристики
└── ui.py               # элементы интерфейса
```

Подробный контракт встроенной нейросети находится в [NEURAL_MODEL_CONTRACT.md](NEURAL_MODEL_CONTRACT.md).
